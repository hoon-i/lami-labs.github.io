# 멤버 사진 폴더

- 기본 사진: `<카테고리 폴더>/<slug>.jpg` (예: `intern/jeonghun-hong.jpg`)
- 마우스 hover 시 바뀌는 사진(선택): `hidden/<slug>.jpg`
- 3:4 세로 비율 권장. `<slug>`는 해당 멤버 YAML(`data/members/...`)의 `slug` 값과 같아야 합니다.

| 폴더 | 카테고리 |
|---|---|
| professor/ | PI |
| postdoc/ | Postdoc |
| phd/ | PhD Students |
| integrated/ | Integrated Students |
| master/ | Master Students |
| intern/ | Interns |
